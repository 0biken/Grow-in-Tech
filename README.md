# Grow-in-Tech

Official website for Grow In Tech (GiT), University of Ibadan.

The current visual implementation reference is [BRAND_GUIDE.md](BRAND_GUIDE.md), aligned with the supplied GIT brand deck. The PRD remains the functional reference.

Run `npm install`, then `npm run dev` for local development. Use `npm run build` and `npm run lint` before shipping changes.
