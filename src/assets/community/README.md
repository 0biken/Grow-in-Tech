# Community photos

Drop real GiT photos here and they replace the illustrative stock photo in that
slot automatically, with no code changes. The file name (without extension)
must match a slot name. Supported formats are jpg, jpeg, png, webp and avif.

| Slot | Where it appears | Suggested shot |
| --- | --- | --- |
| `hero` | Home hero, full-bleed | Wide crowd or group shot, landscape, at least 2400px wide |
| `circle` | Home bento, large card | A small group learning together |
| `friends` | Home manifesto, inline pill | Candid faces |
| `stage` | Home impact column | A speaker or trainer mid-session |
| `panel` | Programs recap hero | A panel or session in progress |
| `learner` | Home manifesto, inline pill; Get Involved | One person focused on a laptop |
| `builder` | Home bento, hackathon card | People building or pair-working |
| `crowd` | Home impact column; About | An energetic group shot |
| `portrait` | Home manifesto, inline pill | A single smiling member |
| `together` | About; footer mosaic | Friends or the committee together |

Photos from `src/assets` are fingerprinted and optimized by Vite at build
time. Ask for consent before publishing identifiable people.
